Sample data How this page works

Hospitals and payers are fictional and every price is generated sample data. This page has no Vue code of its own: it loads one script, cairn-wc.js, and uses the same components as the Vue demo as native custom elements.

  • Django renders the page and passes data to components as attributes (JSON for arrays).
  • The combobox fires a change event; HTMX requests /rates and swaps in the partial.
  • The partial is a <cn-data-table> whose rows come straight from the server.
  • Theme tokens are CSS custom properties, which inherit into each component’s shadow DOM.
